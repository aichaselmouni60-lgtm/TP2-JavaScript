# TP2 - Gestion de catalogue de produits

## Description
Ce projet consiste à gérer un catalogue de produits en utilisant JavaScript et Node.js.

## Fonctionnalités
- Afficher la liste des produits.
- Vérifier la validité des données.
- Afficher les produits disponibles.
- Calculer la valeur totale du stock.
- Trouver le produit disponible le moins cher.
- Afficher un résumé des produits.

## Tests
Le programme contient plusieurs tests :
- Vérifier qu'un produit sans stock n'est pas disponible.
- Vérifier le cas où aucun produit n'est disponible.
- Tester un catalogue vide.
- Vérifier les données invalides.

## Technologies utilisées
- JavaScript
- Node.js

## Exécution
Pour exécuter le programme, utiliser la commande :

```bash
node produits.js
```
